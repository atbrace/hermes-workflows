fix(wf): the child prompt now states the run dir

Gateway-served seats run their terminal inside the gateway daemon
(systemd-unit env), so the per-spawn HERMES_WF_* env pins cannot reach the
seat shell — measured, rdirprobe series. The prompt is the one channel that
always reaches a seat: every child prompt now carries "Run dir: <abs path>"
plus an export hint, beside WORK_DIR_NOTE in the GOAL half. Seats stop
burning turns rediscovering their run dir.
